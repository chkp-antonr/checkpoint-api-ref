# set-simple-gateway remove alias from platform portal web settings

**Collection:** Web API (version 2.1) > 62 Simple Gateway
**Method:** `POST`
**URL:** `{{server}}/v2.1/set-simple-gateway`

## Request Headers

| Header | Value |
|--------|-------|
| Content-Type |  application/json |
| X-chkp-sid |  {{session}} |

## Request Body

**Mode:** `raw`

```json
{
  "name": "gw1",
  "platform-portal-settings": {
    "portal-web-settings": {
      "aliases": {
        "remove": "www.newAlias1.com"
      }
    }
  }
}
```
