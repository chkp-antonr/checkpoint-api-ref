# add-vpn-community-meshed (route based)

**Collection:** Web API (version 2.1) > 107 VPN Community Meshed
**Method:** `POST`
**URL:** `{{server}}/v2.1/add-vpn-community-meshed`

## Description

Adds a new Route Based Meshed VPN Community

## Request Headers

| Header | Value |
|--------|-------|
| Content-Type |  application/json |
| X-chkp-sid |  {{session}} |

## Request Body

**Mode:** `raw`

```json
{
  "name": "RouteBased_Meshed_VPN_Community",
  "routing-mode": "route_based",
  "gateways": [
    "gateway_1",
    "gateway_2"
  ]
}
```
